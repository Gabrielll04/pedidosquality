Como funciona?

  1. 1. Converse com a assistente aqui ao lado — pode escrever tudo de uma vez, ex: "Sou Ana, quero bolo de chocolate 2kg para sábado, meu zap é 11998761234".
  2. 2. A IA interpreta seu pedido (setor, serviço, telefone, data, valor).
  3. 3. Você confere o resumo e confirma.
  4. 4. O pedido é criado automaticamente no sistema da loja (Supabase).

Inteligência Artificial

O chatbot usa o modelo GPT-OSS via Groq para entender frases livres (setor, serviço, telefone, data, valor) — com IA local de fallback se a API falhar. Para ativar a IA avançada neste navegador:

  1. Crie uma chave em console.groq.com → API Keys (gratuito).
  2. Cole abaixo. Ela fica salva só neste navegador (não vai para o Git).
  3. Para valer para todos os visitantes, configure um proxy com a chave em segredo (ex: Cloudflare Worker) — fale com o desenvolvedor.
